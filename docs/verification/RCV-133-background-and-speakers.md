# RCV-133 · NPC 来源与后台进度

人物说法在候选及实际事件两处按人物 ID、同场条件和本人所信的值校验。主角世界话题的未知来源标签进入拒绝路径；观察与公开告示有约定值。死亡状态的人不进入交谈与收件人材料。名称解析识别公开 name；同名歧义仍需单独裁决。GM 工具能切换至当前公开在场的临时人物。普通玩家工具依然固定主角。

人物反思使用独立的 character_reflected 事件，只投影到 arc，带有输入事件出处。明确的非 arc 输出失败后保留待处理经历；累加公开人物经历、冷重开按有效历史恢复。新回合仅为有新经历的人触发。拟合跨行动时的历史重要度使用确定性评分。角色反思失败与摘要处理分别结算。未给每个 NPC 自动生成私有解释。

超预算的追赶工作进入可重放队列；仍在场的待办下回合优先处理。没有进入队列的持续在场人物不会被重复当作离场回归。主角锚点不再按异地镇处理。兜底支线记录事件出处、调查地点、一个可演进阶段及三天寿命。地区生成返回零行时，下个游戏日重试。导演按具体访问次数和线索实际推进事件计龄。

复跑 RCV-130 的 ordinary GUI 原反例：正确人物弧产生且普通行动发布；错误世界值经 mara 与“玛拉亲口”两种来源均被拒；死者收件列表为空；兜底线有锚点、阶段和寿命，跳日发生阶段变化。温读最近八段时，100/1000/5000 条合成旁白的五次中位数 1.74/8.85/44.17 ms，整个仪表盘仍有其他随档长增长的路径。回归覆盖跨三次行动反思、非法知识写入、预算分两次处理及失败播种隔日恢复。全量的最终累计结果见 RCV-134。
