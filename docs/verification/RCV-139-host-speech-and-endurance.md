# RCV-139 · 宿主交付发言与百回合世界验证

修前真实样本中，作者在正文写出了玩家选定的发言，却漏了 knowledge 段。普通行动发布，SQLite 没有这次发言的收据，冷重开后无法查到原话。这是写入缺口。没有从当时的正文或摘要给历史存档补造收据。[修前原始样本](rcv138-terra-recall/review.md)

普通 GUI/CLI 现在从玩家明确选择的收件人和逐字原话生成通信事件。当前同场的发言按行动开始日记录在离开之前，附条件的抵达发言仅在实际抵达后交付。实际发布的事件必须与宿主要求逐项匹配。模型仍不能替用户选收件人或原话；导入器的条件授权沿用原来的语义。重复提交同一 action_id 只发布一次，新的回合可以再次发送完全相同的话，每次出现有单独的日期、回合和来源引用。撤回后按有效事件恢复。

## 普通入口的 Terra 验收

两个收件人的两次自然作者响应都省略了 knowledge。宿主分别补上收据，最终正文按既定结果生成。离场、冷重开后，阿岚与阿禾分别只持自己的原话；玩家能按收件人和日期查原文，调换收件人和查询未说过的话都返回无匹配。打开原文与邻文、查询前后版本和事件数已核对。查证过程零模型调用。该样本使用合成存档，关闭无关后台；跨日重复发言与条件抵达由确定性测试覆盖。[原始请求、响应、读回结果](rcv139-terra-speech/review.md)

## 百回合验证

运行 `.venv/bin/python docs/verification/rcv139/world_endurance.py`。普通非演示入口，作者、审稿、后台生成均用确定性替身，后台钩子全部启用。三个预置地区线每个游戏日必定推进。100 个有效回合，从第 1 天到第 11 天，508 条有效事件。三条线各十个不同阶段，道路先关闭后恢复，调查凭实地原文只结案一次。第 25、50、75、100 回合各冷重开一次，第 50 回合另撤回并重走；101 次作者调用包含被撤回的那一次。第 1 天和第 5 天对阿岚说同一句话分别留存，第 3 天对另一人的话没有写进阿岚的认知。远处暗线的秘密标记没有出现在前台作者请求中。该运行覆盖状态与调度，不提供百回合自然生成质量的估计。[结果计数](rcv139/world_endurance.json)

完整门禁在 Python 3.12.14 下重新执行，得到 **2267 passed, 1 deselected in 53.01s**。沿用既有 slow 排除范围。所有模型样本为本地原生生产协议试验，未调用真实远端 HTTP、下载 embedding 权重或读取用户存档。
