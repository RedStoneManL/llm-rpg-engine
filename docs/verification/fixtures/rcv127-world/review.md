# 世界多线长局验收评审

## 可复现的机械结果

使用真实 run_turn、SQLite 存档和 AuthorStrategy。两个独立异地暗线分别为 simple 和 medium；阈值 100、各 30 阶段、寿命 40 天，使观察窗口内每次合格推进必然可见。主线是已公开的北塔旧账。前台回复使用确定性替身；真实模型采样只发生在回访后明确标记的两回合。

修前基线为 7008259：80 个北塔镇行动中前 64 个各过一个时段、后 16 个未过时段，到第 17 天晨；南桥的两线仍为 -1。冷重开状态一致。第 81 行动实际返回南桥后，两线才各推进到 0。结果存于 before_long；用归档的 7008259 和当前验收脚本重跑获得 PASS。

相同机械条件下修后：第 2 至 17 天，两条远线各每日推进一次，共各 16 次，到回访前 stage 15；同日末尾 16 次行动没有额外远处推进。第 81 行动回到本地后，两线各按本地节奏推进到 16。回访边界冷重开一致；主线仍为明态。离开期间的作者请求按暗线 ID 和内容标记检查，无远处线索泄漏。对应 after_long。

24 行动对照仅跨一次日界，适合核查回访细节，不代表长期概率：修前回访前两线 -1，修后两线 0；真实返回当天，分别到 0 和 1。before_detailed 和 after_detailed 的回访后输入直接点名两线并提到主线，不能当作自然发现测试。修后模型回应把停转木轮与重系的缆绳分开，下一回合呈现麦袋及候船人，没有认定与北塔旧账有关；但“磨坊与渡口各有人事可问”比给定线索稍作了推测，未建立可交互人物。

## 中性输入与模型评价

另设 after_neutral_demote：80 行动后回访，其第 16–20 阶段专设具体可观察线索，玩家接连输入“我在集市停下来观察周围”“我继续留意眼前的动静”，未点名暗线及主线。此样本真实启用离场降暗 hook；其他摘要、导演、级联、追赶、密度 hook 禁用。第一个原生响应自发呈现匠人修木销、船夫写渡船时刻；第二个呈现磨坊前排队麦袋与渡口待装货包。未虚构其与北塔旧账的因果关系；主线留在每轮明账，正文没有强行提及。主任务 fixture 未指定 A 镇 anchor，本样本仅覆盖空闲及跨镇后公开账本保留，不能单独证明有锚点任务的离场行为。

逐份原样保存生产请求和此会话 Terra 响应，响应回放后 PASS。它是单次自生成自评、非远端 HTTP 测试；不能推出模型群体稳定性。停用摘要使 80 回合的待摘要原文高度重复，这本身限制了场景自然度；这里没有测完整后台负载、其他阈值统计、自然模型驱动的 80 回合、概率分布或复杂暗线终局。局部可观察动作写入叙事不等于创建持久可交互 NPC。

## 重跑

当前工作树：

```
.venv/bin/python scripts/verify_world_threads_native.py long /tmp/rcv127-after-long advance
.venv/bin/python scripts/verify_world_threads_native.py neutral docs/verification/fixtures/rcv127-world/after_neutral_demote advance

```

复用已有 responses.json 的请求严格比对；空目录会在首个原生请求暂停并写 pending.json，需逐次真实生成并填入 responses.json。基线可将 7008259 归档到隔离目录、复制当前脚本并用现有 Python 运行 `long <新目录> frozen`。机械断言覆盖时钟、两线阶段及远处每线每天最多一条推进、主线活跃、未到场时无暗线标记、冷重开及实际移动返回；文本质量由本评审而非机械 PASS 判断。旧证据目录保持隔离保存；新的脚本仅记录前台替身请求数、无泄漏检查和哈希，保留两轮原生完整请求响应。
