# 普通作者的邻地私话复验

5 条响应均针对当前版本生产请求逐份生成，并经普通 PlayerDashboard、AuthorStrategy 和 SQLite 实际提交。角色各自在不同镇，玩家只明确对阿岚说纸鹤原话；随后询问阿岚，冷重开，前往白禾处并询问，再返回阿岚处。逐回合生成的原始请求和响应保存在 requests.json / responses.json，状态、知识事件和每回合当前安全交谈材料在 result.json。

进入白禾所在镇后，普通作者收到白禾自己的“听说只在上午通航”，以及条件抵达阿岚处的公开来源材料；这些安全交谈/抵达材料不含给阿岚的逐字纸鹤话。白禾没有持久化该原话，白禾正文也没有引用它；回阿岚处后，同场安全交谈材料再次包含阿岚经可信事件验证听到的原话。冷重开前后知识投影一致。两个角色的不同认知和公开停航值未被互相覆盖，幕后秘密没有进入请求；未说出的心念没有被两名角色记录或说出。

这里的检查针对新组装的安全交谈/条件抵达材料和角色知识记录，不声称整个主持人 provider 历史完全不知道这句话。模型作为共享叙述者此前接收过玩家输入，最近剧情也仍出现“你只把纸鹤的那句话说给阿岚听”；这些不是白禾被授权知晓的证据。白禾问答输入属于自由文本，并非一次明确选择白禾的 host 逐字收据，因此本样本没有验证第二个显式定向对话回合。

语句方面，阿岚把旧告示的全天通航表述为旧信息并表示现在不确定，白禾把上午通航保留为听说并表示今天不确定；两处“不确定”是审慎补充，不是种子中单独保存的事实。没有在正文观察到把两人认知说成公共真相。人物并非多次采样：这是同一 Terra 会话对一条固定路线的生成与自评。关闭摘要、导演、级联、追赶、密度和降暗 hook，保留 run_lore；不是远程 HTTP 测试。
