# RCV-135 · 调查依据、导演队列和历史状态

调查可以在本地接取时声明 investigate，指定地点与可核验的设施。正常结案需要引用接取以后有效公开观察的事件 ID 与原文，有类型约定时还要匹配地点和设施。交付仍走物权裁决。自由任务没有可比对的结构化目标，引用的语义相关性仍有边界。普通 GUI 回归实际尝试无凭据、引用西墙水井、引用北墙梯子三次，仅最后一次结案；撤回恢复未结案状态。地点观察按设施区分，同范围多个对象能共存。

导演给有既定节拍的线记录实际节拍内容，并按来源逐条展示和确认，重开可重放。一条线的提示不再顺带确认另一条。玩家线索、角色听说及世界事实有不同边界，告示只证明信息来自告示。作过证或收到通信的临时人物可以参与补演。开场提示传入角色目标和 NPC 的地点，禁用世界书词条被过滤，启用词作为翻译约束交给转换器；通用世界书触发系统仍有待开发。

当前图支持按游戏日与回合查事实的当时版本和来源，GM 工具可用。跨日行动的输入原文按起始日定位。相同版本的 GUI 刷新在 SQLite 的同一读事务比较版本，无需把完整事件表读进内存。重跑 RCV-130 的 100 / 1000 / 5000 段合成旁白热读，五次中位数 0.88 / 1.02 / 1.00 ms，均显示最近八段。该数据是本机读模型测量。
