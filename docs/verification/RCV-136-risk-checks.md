# RCV-136 · 普通行动可明示风险检定

在 CLI 或 GUI 输入“检定 潜行 困难 绕过守卫”。潜行、交涉、强攻共用一套宿主规则。三档难度的 d100 成功线分别为 75、55、35，随后 20 点为付出代价的成功，再往上为受挫。成功耗一个时段，其他两类耗两个时段。当前由单人玩家明示难度。这些数值是本轮选择的初始玩法参数，没有经过平衡性统计。

骰子取自 campaign seed、角色、地点与回合。作者拿到已定结果后才写动作，时钟需匹配。受挫不允许前台照常发放物品、移动或写任务成功；后台世界仍按时推进。普通权限继续限制成功声明的效果。重复请求、撤回、独立读回以及三种结果都有确定性回归。检定仅结算尝试与时间，资源账本在此回合固定；行贿付款须另行实际结算。尚无任意自然语句的风险分类、角色属性加值或完整战斗系统。

[Terra 明示潜行原生样本](rcv136-terra-check/review.md)：固定 seed 2，投出 58，困难成功线 35，受挫。两个时段后仍在客栈，灯仍在手；原生作者、独立审稿、面板和 SQLite 结果一致。冷重开保留结果，重复请求仍只有一条检定。使用合成存档、普通非演示入口、本地原生请求与响应，关闭无关后台。
