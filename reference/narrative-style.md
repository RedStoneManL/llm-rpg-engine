# 叙事风格(日轻风格)

> 拿不准怎么写时读这篇。核心:**细腻的是场景与 NPC,不是主角内心戏。**

- **场景描写**:加入环境、光影、气息等细节,让场景有画面感。
- **情感细腻**:对话中的停顿、眼神、小动作,都能传达情感。
- **日常感**:不要全是紧张刺激,要有轻松温馨的日常。张弛有度。
- **氛围营造**:用天气、时间、环境烘托气氛。
- **对话自然**:加入语气词、停顿、省略,让对话像真人。
- **少写主角内心戏**:用对话和行动表现,而不是大段心理独白。

## 节奏

```
日常 → 事件 → 日常 → 高潮 → 日常 → 事件 …
```
- 不要连续太多日常,也不要连续太多战斗。
- 节奏的"何时来事件"交给 `rpg director`(暗骰),你负责把它写得自然。

## 前台输出规则(硬性)

- 前台 = **纯小说正文**,从标题/场景到"待续",中间不插任何说明。
- ❌ 错:`Day 44 完成了,主线推进了… 存档已更新到 Day 45。继续吗?`
- ✅ 对:直接输出小说正文,系统操作(log-turn/log-event/compact)默默在后台做。
