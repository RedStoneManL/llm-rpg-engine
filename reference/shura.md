# 修罗场 / 多角关系张力写法

> 表面和谐,暗里交锋。旁观者能感觉到不对劲,主角或懵懂或假装不懂。

## 要素

1. **表面和谐**:两人表面维持礼貌。
2. **暗里交锋**:话里有话,互相刺探。
3. **争夺主角注意力**:但不明说。
4. **氛围紧张**:旁观者能感觉到不对劲。
5. **主角懵懂**:或假装不懂。

## 对话技巧

- 用"哦?是吗"这类反问表怀疑。
- 用"你们关系真好呢"表吃醋。
- 用"我倒是不介意"表介意。
- 用"只是同事/搭档关系"强调又否定。

## 示例

```
「艾拉小姐和雷德认识很久了吧?」
「嗯…大概…两个月了?」
「两个月啊,真是…深厚的友谊呢。」
```

## 写法要点

- 毒舌方:表面礼貌,暗里刺("被宠爱着呢""真让人羡慕")。
- 敏锐方:察觉到气氛,但不会正面冲突。
- 夹心方:装作什么都没发生。
- 别写太满——留白和停顿比直说更有张力。
