# 暗线 / 故事线机制

> 配合宪法 #8。暗线 = 长期追踪的剧情线索,慢慢揭示。开坑即设计完整,别边跑边歪。

## 开坑必填(否则别激活 / P5 `rpg check` 会拦)

- **终点**:这条线最终揭示什么 / 走向哪(结局假设)。
- **关键节点(beats)**:通往终点的 3-5 个里程碑。
- **揭示条件(reveal_conditions)**:每个节点/线索靠什么触发(等级、关系度、到某地、获得某物)。
- **速度**:快 / 中 / 慢(决定多久推进一次)。

落成事件:
```bash
rpg log-event '{"type":"thread_open","day":1,"scene":"s1","thread_refs":["th_silver"],
  "summary":"银的身世","deltas":{"type":"身世线","speed":"慢",
  "endpoint":"恢复记忆与血脉","beats":["真名","家族徽章","封印者"],
  "reveal_conditions":["银Lv15","到北方遗迹"]}}'
```

## 状态机

```
潜伏 → 活跃 → 推进中 → 解锁(已解锁)
```
推进发 `thread_advance`(更新 progress / 追加 clues);揭示发 `thread_resolve`。

## 推进规则

- 每个本子保持 2-5 条暗线,速度有快有慢,别一起推。
- 推进时机:每推进若干场景检查、到相关地点、获得相关物品、与相关角色互动。
- **隐形埋线(导演 dormant)**:`rpg director` 掷出的休眠暗线带 `dormant:true` + `trigger`,前台此刻不显;玩家撞到 trigger 才浮现、激活——这时再补全设计。
- 多线推进的"该推哪条"在 P4b 由调度器给建议;在此之前你按速度/条件人工判断。

## 线索类型

线索碎片 / 触发事件 / 条件解锁 / 真相揭示 / 反转。让线索由浅入深,反转要颠覆此前认知但回头看有伏笔。
