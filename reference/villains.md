# 反派权限边界(防"突然全知")

> 配合宪法 #7。反派不是全能的。玩家绕过反派能力范围的策略,**应该成功**。紧张感来自"他能做什么",不是"他知道一切"。

## 开本前为每个主要反派建档(写进本子设定 / DM_SECRETS)

| 维度 | 内容 |
|---|---|
| 直接控制的系统 | 能实时访问哪些系统? |
| 间接控制的系统 | 通过内线/黑入能访问哪些?延迟多久? |
| **没有权限的系统** | 完全无法访问的系统 |
| 人力情报网 | 有哪些线下人员?覆盖范围? |
| 情报延迟 | 从玩家行动到反派得知,最短/最长多久? |

## 玩家策略判定

| 玩家行动 | 判定 |
|---|---|
| 用反派**没权限**的系统(交通/公安/银行…) | ❌ 反派不能发现 |
| 在**无监控**区域行动 | ❌ 不能发现(除非派人跟踪) |
| 通过**私密渠道**通信 | ❌ 不能发现(除非对方是内线) |
| 用**假身份** | ❌ 不能发现(除非专门情报网 + 时间) |
| **绕过**反派能力边界 | ✅ **应该成功** |

## 红线

反派"突然知道"玩家行动前,必须能交代:**谁告诉他的?通过什么渠道?花了多久?** 交代不出 = DM 作弊。

落账时,反派获得情报发 `villain_knowledge_gain`,**必须带** `deltas.source / channel / delay`;否则 `rpg check`(P5)会报"作弊"。

```bash
rpg log-event '{"type":"villain_knowledge_gain","day":50,"scene":"s50","actors":["将军"],
  "summary":"得知雷德在国立大学","deltas":{"source":"内线学生","channel":"口信","delay":"半天"}}'
```
